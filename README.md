# World-building Project

A home for the fictional Aegaea world and its simulation-oriented geological datasets.

The Aegaea tectonics v1 dataset is developed from an upside-down, horizontally mirrored fictional world map and **does not reuse modern Earth's tectonic plate boundaries**.

See [`data/aegaea/tectonics/v1/`](data/aegaea/tectonics/v1/) for plate kinematics, cratons, plate contacts, crustal provinces, and geological scenario documentation.

Scientific status: experimental synthetic atlas; present-day plate/contact assignments are not a dynamically reconstructed geological history.
